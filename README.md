      <h3>🔍 RAY-IMAGE</h3>
      <p><b>From-scratch text-to-image research</b></p>
      <p>An experimental image-generation pipeline built around a custom VAE, an approximately 60M-parameter Diffusion Transformer (DiT v3), flow matching, frozen Qwen3-4B text conditioning, and a cached embedding workflow.</p>
      <p><b>Engineering focus:</b> training stability, checkpoint/resume safeguards, EMA, caption dropout, classifier-free guidance, data-cache integrity, and honest evaluation.</p>
      <p><b>Status:</b> research release; current samples are experimental and often impressionistic. Consistent object geometry and prompt adherence remain open problems.</p>
